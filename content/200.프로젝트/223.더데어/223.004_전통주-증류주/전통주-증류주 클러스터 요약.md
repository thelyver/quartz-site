# 🏺 전통주/증류주 산업 클러스터 (영암·무안·신안)

## 사업 개요

> [!abstract] 핵심 한 줄
> 전남 서남권 3개 군의 프리미엄 증류주 산업 클러스터 구축. 농업→제조→관광→교육→해외진출 5단 밸류체인

**위치**: 영암군·무안군·신안군 (서삼석 의원 지역구)
**추진 주체**: 서삼석 국회의원 + DIT + 술아원 + JCK와인스쿨
**정책화 전략**: 국비 지정 → 타당성/기본계획 용역 → 클러스터 구축

## 5단 밸류체인

```
1️⃣ 원료  →  2️⃣ 제조  →  3️⃣ 관광·체험  →  4️⃣ 교육·인력  →  5️⃣ 해외진출
(계약재배)   (증류·QC)    (양조장 투어)     (인재양성)       (뉴욕 등)
```

## 핵심 인프라

| 구성요소 | 담당 | 비고 |
|---------|------|------|
| 증류·QC | 술아원 (강진희 대표) | 6차산업 인증, 찾아가는 양조장 |
| 교육·QC | JCK 와인스쿨 (김준철 원장) | 전문 인력 양성 |
| 기술 자문 | 전영욱 수석연구원 | 주류 대기업 출신 |
| 해외진출 | DIT (디유넷) | 바이어 네트워크, 플랫폼 |
| 정책 | 서삼석 의원 | 농림축산식품해양수산위 |
| 지역 협력 | 정일창 부회장 | 무안 지역 실행 |
