# 아이디어 메모

**제목**: AI 예산별 와인 선물 패키지 빌더
**작성자**: 강수근 | **작성일**: 2026-06-30 | **상태**: 초안
**태그**: #데어에이 #AI활용지원 #혁신소상공인 #특판 #선물패키지 #예산기반

## 1. 한 줄 요약
예산 구간별로 와인+포장+메시지카드+배송 옵션을 자동 구성하고, 기업 총예산 입력 시 1인당 단가·수량에 맞춘 패키지를 산출한다.

## 2. 배경 / 문제 정의
- 선물 구매자는 '얼마짜리를 어떻게 구성할지'에서 가장 막힌다.
- 예산은 선물 의사결정의 1차 기준인데, 매번 수작업 구성은 비효율적이다.
- 추석·설·연말·승진·창립기념일 등 시즌별 수요가 반복된다.

## 3. 핵심 아이디어
- 예산 구간별(3/5/7/10/20만원) 패키지 템플릿 자동 생성
- 기업 총예산 입력 → 1인당 단가·수량 역산 구성
- 시즌별 템플릿(명절/연말/승진/창립)
- 1번 제안서 생성기의 입력 모듈로 결합 가능

## 4. 기대 효과
- 즉시 견적 가능한 상품 라인업 확보
- 상담 없이도 표준 패키지로 전환율 향상
- B2C 선물·B2B 특판 양쪽 활용

## 5. 전제와 리스크
- **[검증 필요]** 예산 구간별로 실제 마진이 확보되는 상품 조합 존재 여부 — 원가·재고 데이터 필요
- 단독 기능으로는 약하며 1번·3번과 묶여야 사업성 선명
- 포장·배송 옵션의 실제 운영 단가가 패키지 손익을 좌우

## 6. 다음 단계

- [ ] 1번 제안서 생성기와의 결합 지점 정의
