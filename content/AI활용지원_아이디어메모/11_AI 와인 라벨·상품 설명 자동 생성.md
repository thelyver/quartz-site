# 아이디어 메모

**제목**: AI 와인 라벨·상품 설명 자동 생성
**작성자**: 강수근 | **작성일**: 2026-06-30 | **상태**: 초안
**태그**: #데어에이 #AI활용지원 #혁신소상공인 #상품등록 #콘텐츠 #업무효율

## 1. 한 줄 요약
수입사 자료·테이스팅 노트·가격·페어링을 입력하면 홈페이지용 설명, 카드뉴스, 문자 메시지 문구를 자동 생성한다.

## 2. 배경 / 문제 정의
- 상품 1개 등록에 30~60분이 드는 반복 업무가 직원 시간을 잠식한다.
- 설명문은 채널별로 톤이 달라 매번 재작성이 필요하다.

## 3. 핵심 아이디어
- 입력: 와인명·산지·품종·가격·테이스팅 노트·페어링
- 출력: 홈페이지 설명/카드뉴스/문자 등 채널별 문구
- 23번 DB 구축과 결합하면 등록 파이프라인 완성

## 4. 기대 효과
- 상품 등록시간 30~60분 → 5~10분
- 채널별 문구 일관성
- 콘텐츠(18·19번) 기반 데이터 확보

## 5. 전제와 리스크
- **[검증 필요]** 주류광고 금지표현 위반 가능성 → 12번 검수기 필수
- AI 생성 설명의 사실 오류(산지·빈티지)
- 수입사 자료 형식 다양성

## 6. 다음 단계
- [ ] 채널별 문구 템플릿 정의
- [ ] 12번 금지표현 검수 연계
- [ ] 23번 DB 구축과 파이프라인 연결

## 7. 참고
- 엠지 리서치 10번·2차 9번(80점)
