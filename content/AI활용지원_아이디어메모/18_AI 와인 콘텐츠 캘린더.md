# 아이디어 메모

**제목**: AI 와인 콘텐츠 캘린더
**작성자**: 강수근 | **작성일**: 2026-06-30 | **상태**: 초안
**태그**: #데어에이 #AI활용지원 #혁신소상공인 #마케팅 #콘텐츠 #SNS

## 1. 한 줄 요약
보유 와인 DB에서 매주 3~4개 콘텐츠 주제를 자동 생성한다(페어링·가격대 선물·오늘의 입고 등).

## 2. 배경 / 문제 정의
- 콘텐츠는 꾸준함이 핵심인데 1인 운영에서 소재 발굴이 병목.
- 보유 DB가 있으면 소재는 무한히 파생 가능.

## 3. 핵심 아이디어
- DB 기반 주간 콘텐츠 주제 자동 생성
- 19번 스크립트 생성기로 연결
- 시즌 모듈(16번) 흡수

## 4. 기대 효과
- 콘텐츠 발행 지속성
- 소재 발굴 시간 절감
- 브랜딩·유입 강화

## 5. 전제와 리스크
- **[검증 필요]** 보유 와인 DB 존재(미구축 시 소재 부족)
- 단독 강조 시 '흔한 사업계획서'로 보일 위험
- 콘텐츠→매출 연결 측정 어려움

## 6. 다음 단계

- [ ] 19번 스크립트 생성 연계
