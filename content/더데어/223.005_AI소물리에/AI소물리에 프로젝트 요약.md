# 🤖 AI 소믈리에 (더데어)

## 사업 개요

> [!abstract] 핵심 한 줄
> Replit 기반 웹앱 형태의 AI 와인 추천 서비스. 자연어 질문 + 버튼 필터 하이브리드 시스템

**테스트 URL**: https://wine-ai.replit.app/
**개발 단계**: MVP(프로토타입 v0) 진행 중

## 기술 스택

| 구성 | 기술 |
|------|------|
| 프론트엔드 | React |
| 백엔드 | Node.js |
| 데이터베이스 | PostgreSQL |
| AI/LLM | OpenAI API |
| 검색 | RAG (Retrieval Augmented Generation) |
| 배포 | Replit |

## 핵심 기능

```
1. 자연어 추천
   사용자 입력 → AI 소믈리에 톤으로 와인 추천 (단일 턴)

2. 버튼형 필터 검색
   포도 품종 / 산지 / 가격대 / 스타일 → 구조화 검색

3. 데이터 파이프라인
   WineList.csv → RDB 자동 적재 → KeywordLib 구축
```

## 데이터 자산

- **WineList.csv**: 와인 목록 (와인21닷컴 데이터 활용 가능)
- **KeywordLib**: 와인 관련 키워드 라이브러리 구축 중
- **참고**: [[와인21닷컴 프로젝트 요약]] 데이터와 연동 가능

## 디자인 레퍼런스

- **Wine.com** (이커머스 + 필터 검색)
