# 🧭 벤치마킹 템플릿 사용 가이드

## 1. 이 템플릿은 무엇인가

팀 내 누가 어느 사이트를 조사하든 **같은 항목·같은 기준**으로 결과가 모이도록 만든 표준 양식입니다. 결과는 PM이 비교·시사점 도출 단계에서 그대로 합칠 수 있는 형태가 됩니다.

## 2. 폴더 구성

```
_벤치마킹_TEMPLATE/
├── 00_사용가이드.md           ← 지금 이 문서
├── 01_카드_TEMPLATE.md        ← 사이트 1개당 1장 (복제해서 사용)
├── 02_종합표_TEMPLATE.md      ← 마크다운 종합표 (선택 사용)
└── 03_종합표_TEMPLATE.xlsx    ← 엑셀 종합표 (권장 — 정렬·필터·집계 용이)
```

## 3. 어떤 흐름으로 쓰나

```
[1] 조사 대상 배정       (PM이 영역·사이트 할당)
        ↓
[2] 카드 작성 (.md)      (사이트당 1장, 깊이 있게 채움)
        ↓
[3] 종합표 등록 (.xlsx)  (카드의 핵심을 1행으로 요약 입력)
        ↓
[4] PM 검토·시사점 도출  (종합표에서 비교, 카드는 근거자료로 참조)
```

권장 분담: **카드(.md) = 조사자**, **종합표 1행 등재 = 조사자**, **시사점 종합 = PM**.

## 4. 항목 정의 (입력 일관성 확보용)

### 4.1 영역 (프로젝트)
다음 4개 중 택 1로 입력 (정확히 표기):
- `AI소믈리에`
- `와인21닷컴B2B`
- `디유박스`
- `전통주클러스터`
- `기타` (포트폴리오 외 참고용)

### 4.2 관점 (카테고리)
다음 4개 중 택 1 (필요시 복수 선택은 카드에만, 종합표는 주관점 1개):
- `비즈니스모델`
- `제품·UX`
- `데이터·AI`
- `정책·산업생태`

### 4.3 적용 우선순위
- `HIGH` — 본 사업에 즉시 반영 검토할 만한 사례
- `MED` — 시사점은 있으나 단기 적용 어려움
- `LOW` — 참고용

### 4.4 신뢰도
- `확실` — 공식 사이트·언론·공시 등으로 검증
- `추정` — 한두 출처에서만 확인
- `미확인` — 정보가 불완전, 추가 조사 필요

### 4.5 출처 표기 규칙
- URL 표기 시 **접속일** 명시 (예: `https://example.com (조사일: 2026-04-28)`)
- 언론 기사는 매체명·기사 제목·일자
- 직접 사이트 외 정보는 반드시 출처 명시 — 추정은 "추정" 표기 필수

## 5. 작성 시 원칙

> [!warning] 절대 규칙
> - **확인 안 된 정보는 쓰지 않는다.** 채우기 어려우면 `미확인`으로 두고 비워둔다.
> - **본 사업 시사점**은 조사자의 1차 의견을 짧게 적는다. 정답을 쓰는 칸이 아님.
> - **수치·통계 인용 시 출처 필수.** 출처 없는 수치는 빈 칸이 낫다.

## 6. 카드 → 종합표 매핑

| 카드의 어느 칸 | → | 종합표의 어느 컬럼 |
|--------------|---|----------------|
| 명칭 / URL / 운영주체 / 본사위치 | → | F / G / H / I |
| 한 줄 소개 | → | J |
| 주요 기능(상위 3개) | → | K (한 셀에 줄바꿈 또는 ; 구분) |
| BM·수익원 | → | L |
| 핵심 자산 | → | M |
| 강점 / 약점 | → | N / O |
| 본 사업 시사점 | → | P |
| 적용 우선순위 / 신뢰도 | → | Q / R |
| 출처 / 다음 액션 | → | S / T |

## 7. 자주 묻는 질문

**Q. 사이트 정보가 너무 적어서 빈 칸이 많은데 등재해도 되나요?**
A. 네. `미확인`/`추정` 표기 후 등재하고 `다음 액션` 칸에 추가 조사 필요 사항을 명시해 주세요.

**Q. 같은 사이트를 두 영역에 모두 적용하고 싶은데요?**
A. 카드는 1장만 쓰고, 종합표에는 영역만 다른 두 행으로 등재할 수 있습니다. 단 `시사점` 칸은 영역별로 따로 적어 주세요.

**Q. URL이 차단되어 정보를 못 봐요.**
A. 회사명·서비스명으로 우회 검색 → 공개 인터뷰·기사·LinkedIn에서 BM 추정 → `추정` 표기 후 등재.

**Q. 카드 1장 작성에 얼마나 걸리나요?**
A. 조사 포함 60~90분이 적정. 2시간 넘어가면 정보 부족 사이트일 가능성 — `미확인` 처리 후 다음 사이트로 이동 권장.

## 8. 검토 체크리스트 (PM 회수 시)

- [ ] 영역·관점·우선순위·신뢰도 표기 일관
- [ ] 모든 수치에 출처 명시
- [ ] URL 접속일 표기
- [ ] 시사점이 사이트 설명이 아니라 본 사업과의 연결로 적혀 있는가
- [ ] 빈 칸은 의도된 `미확인`인가, 누락인가
